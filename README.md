# Duplicate File Finder

ابزاری با Python برای شناسایی فایل‌های تکراری در یک پوشه و زیرپوشه‌های آن.

این برنامه محتوای فایل‌ها را با الگوریتم SHA-256 بررسی می‌کند و فایل‌هایی را که محتوای یکسان دارند در گروه‌های جداگانه نمایش می‌دهد؛ حتی اگر نام یا محل قرارگیری آن‌ها متفاوت باشد.

## امکانات

- بررسی فایل‌های یک پوشه و زیرپوشه‌ها
- شناسایی فایل‌های تکراری بر اساس محتوا
- محاسبه Hash با الگوریتم SHA-256
- خواندن فایل‌ها به‌صورت بخش‌بندی‌شده
- نمایش مسیر فایل‌های تکراری
- مدیریت خطاهای دسترسی و خواندن فایل
- ارائه گزارش نهایی از عملیات بررسی

## نحوه شناسایی فایل‌های تکراری

برنامه برای هر فایل یک Hash با الگوریتم SHA-256 محاسبه می‌کند.

فایل‌هایی که Hash یکسانی دارند، در یک گروه قرار می‌گیرند.

به همین دلیل، نام فایل‌ها در تشخیص تکراری بودن تأثیری ندارد.

## نکات و محدودیت‌ها

- برنامه فقط فایل‌ها را بررسی می‌کند و آن‌ها را حذف یا تغییر نمی‌دهد.
- فایل‌هایی که دسترسی خواندن آن‌ها وجود ندارد، در گزارش خطا نمایش داده می‌شوند.
- بررسی فایل‌های بسیار بزرگ یا تعداد زیادی فایل ممکن است زمان‌بر باشد.
- این نسخه فقط بر اساس محتوای فایل‌ها مقایسه انجام می‌دهد.

## هدف آموزشی

این پروژه برای تمرین کار با فایل‌ها، مدیریت مسیرها، محاسبه Hash و گروه‌بندی اطلاعات طراحی شده است.

شناسایی فایل‌های تکراری می‌تواند در ابزارهای مدیریت فضای ذخیره‌سازی، پشتیبان‌گیری و اتوماسیون مدیریت فایل کاربرد داشته باشد.
